## 当前边界

规划目标是以 macOS 为本地主脑、Android 为决策界面，并通过微信、小红书、闲鱼、钉钉、飞书等用户提供的 MCP 连接器读取沟通记录和平台身份。Yance 把使用者的多个场景身份、联系人的多个账号和跨平台身份关联起来，从长期互动中学习沟通特征，并根据当前关系和场景推荐回复。早期真实发送逐次确认；长期允许用户在模型和连接器通过验证后，为明确的身份、账号、对象和场景开启可撤销的自动回复。连接器能力、平台稳定性和合规性都不是产品承诺。

以下事项均为 **UNSPECIFIED**：最低系统版本、正式 API、首个真实 connector、数据库、模型、发布政策、安全响应 SLA、owner 和 License。仓库不会用推测填补这些决策。
