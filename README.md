# Yance（言策）

Yance 当前是 **planning-only** 文档项目：仓库不包含可安装发行版、受支持运行时或已实现的公开 API。

## 从哪里开始

- [文档首页](docs/README.md)是当前规划的事实源。
- [开始阅读](docs/getting-started.md)说明如何审阅和参与。

## 当前边界

规划目标是以 macOS 为本地主脑、Android 为决策界面，并通过用户提供的连接器接入外部能力。任何真实发送都必须绑定完整且不可变的待执行载荷，由用户逐次确认。连接器能力、平台稳定性和合规性都不是产品承诺。

以下事项均为 **UNSPECIFIED**：最低系统版本、正式 API、首个真实 connector、数据库、模型、发布政策、安全响应 SLA、owner 和 License。仓库不会用推测填补这些决策。

安全问题请按[安全政策](SECURITY.md)私密报告。文档贡献方式见[贡献指南](CONTRIBUTING.md)。
