# 开始阅读

Yance 当前只有规划材料，没有安装、启动或 archive build quick start。

建议按以下顺序阅读：

1. [项目状态](reference/project-status.md)了解已知与未决边界。
2. [产品定义](product/product-definition.md)了解目标与非目标。
3. [系统架构](architecture/system-architecture.md)和[MCP 耦合层](connectors/mcp-coupling-layer.md)了解职责边界。
4. [隐私、安全与合规边界](reference/privacy-safety.md)了解阻断项。
5. [验证计划](validation/test-plan.md)了解如何证明规划约束。

参与前请阅读[贡献指南](../CONTRIBUTING.md)。发现安全问题时不要公开提交，按[安全政策](../SECURITY.md)使用 GitHub Private Vulnerability Reporting。
