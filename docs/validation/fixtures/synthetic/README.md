# 匿名合成 fixture

本目录只包含固定虚构 ID、`example.invalid`/`.invalid` 标识和合成值，不含真实聊天、账号、附件、Cookie、token 或凭据。每个 `*.valid.json` 必须通过对应 Schema；每个 `*.invalid.json` 必须被拒绝。

这些 fixture 只验证契约结构，不证明产品、connector 或发送能力已实现。
