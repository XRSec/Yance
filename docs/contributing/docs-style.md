# 文档风格

- 用现在时描述文档事实；用“规划”“PROPOSED”“UNTESTED”描述尚未实现的能力。
- 未决维护者或产品承诺统一写 **UNSPECIFIED**，不得用猜测补齐。
- 每个主题只保留一份正文；旧路径只放 `moved` 跳转页。
- 标题按层级递进，链接使用相对规范路径，避免依赖跳转页。
- 高风险主张在出现处链接官方或原始来源，并给出 `last_reviewed`。
- 示例只用合成身份、`.invalid` 域名、固定虚构 ID 和时间，不放聊天原文、账号、凭据或 token。
- 不把 archive build 写成 current quick start。
