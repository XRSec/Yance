# 来源政策

1. 法律、协议、安全边界和平台能力优先引用官方文本；学术准确率与心理测量优先引用原始论文或标准。
2. 高风险结论须 claim-level 引用：链接应紧邻具体主张，不能只依赖集中书目。
3. 社区项目仅证明其自述或生态存在，标记 `self-claim`；不升级为官方、稳定、安全或兼容结论。
4. 每个活动页面的 front matter 记录 `last_reviewed`；来源失效、事实变化或超过复核周期时降级结论。
5. [集中来源页](../research/sources.md)用于去重和发现，不替代原文、正式法律意见或逐条引用。
6. 禁止伪造 URL、访问日期、实验结果或法律结论。无法验证时写 **UNSPECIFIED** 或证据缺口。
